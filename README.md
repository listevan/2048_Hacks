# 2048_Hacks
## Training the model
1. Install requirements.txt in an enviroment
2. Run 
```
python Game_Sim/train_model.py
```
3. The training progress will be printed on the screen
## Testing the model
1. Install requirements.txt if not done before
2. Run
```
python Game_Sim/test_model.py
```
3. Follow CLI instructions
